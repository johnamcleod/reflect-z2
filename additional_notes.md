# ReflectZ2: reflectivity of −d·x₀² + x₁² + ⋯ + xₙ² over totally real fields

Working notes, 6 November 2026. They collect the literature, the monotonicity lemma
with its proof, what is known about bounding d, and a consolidated brief for
Claude Code.

---

## 1. Background: the case over ℚ

**Family.** f_d^n = −d·x₀² + x₁² + ⋯ + xₙ² over ℤ. These forms are isotropic for
n ≥ 4, so the groups are non-cocompact.

| d | Reflective for | Source |
|---|---|---|
| 1 | 2 ≤ n ≤ 19 | Vinberg; Vinberg–Kaplinskaya |
| 2 | 2 ≤ n ≤ 14 | Vinberg; non-reflectivity above 14 in Mcleod's thesis (§3.1.4) |
| 3 | 2 ≤ n ≤ 13 | Mcleod (arXiv:1007.2299; thesis) |
| 5 | 2 ≤ n ≤ 8 | Mark |
| 7, 17 | n = 2, 3 | Mark |
| 11 | n = 2, 3, 4 | Mark |
| 13, 19, 23 | n = 2 only | Mark |

- **Mark,** "Reflection groups of the quadratic form −px₀²+x₁²+⋯+xₙ² with p prime",
  *Publ. Mat.* 59 (2015) 353–372, arXiv:1207.4822. Completes the classification for
  prime p. The arXiv versions differ slightly on p = 11 and 17, so use the
  published version.
- **Mcleod's thesis** (Durham, 2013) classifies the pairs (d, n) over ℚ. For n ≥ 3
  only d ∈ {1, 2, 3, 5, 7, 10, 11, 15, 17} survive.

### How d was bounded over ℚ

1. **Reduction to n = 2** by Bugaenko's theorem (Mcleod's thesis, Thm 3.0.8). If f
   splits as a hyperbolic form f′ plus a one-dimensional unimodular form, the
   fundamental polytope of f′ is a face of the polytope of f. So reflectivity in
   dimension n implies reflectivity in dimension n − 1.
2. **Bound at n = 2:** ⟨−d, 1, 1⟩ must appear in Nikulin's rank-3 classification
   (determinants up to 1365), or 2d must when d is odd. This list is necessary
   but not sufficient: d = 21 is on it, but f²₂₁ is non-reflective.
3. **Vinberg's algorithm** settles each remaining candidate. Non-reflectivity is
   proved with infinite-order isometries (thesis, Appendix A).

## 2. The co-compact setting

Let K be totally real of degree k ≥ 2, O_K its ring of integers, and d ∈ O_K with
d > 0 at the identity embedding and σ(d) < 0 at every other embedding. Then f_d
is admissible and automatically anisotropic, so the group is cocompact.

**Notes on the parameter**
- d and du² give isometric lattices (rescale x₀). So the parameter is d modulo
  (O_K^×)², and the sign of N(d) is forced to be (−1)^{k−1}.
- Over ℚ(√2) and ℚ(√5) there is a unit of norm −1 (1+√2, or (1+√5)/2), and the
  totally positive units are squares. So each principal prime ideal has exactly
  one admissible generator modulo unit squares, whether the prime splits, is
  inert or ramifies. For an inert prime q, for example, d = qε with N(d) = −q².
- The two primes above a split p give genuinely different parameters. Galois
  conjugation does not preserve admissibility with respect to the fixed embedding.
- Root norms are totally positive divisors of 2d, finitely many modulo unit
  squares. Over K ≠ ℚ, divisibility does not bound a root norm at the identity
  embedding. Bugaenko's version of Vinberg's algorithm uses the definite
  conjugate forms to keep each batch finite.

**Known cases of the family**

| Field | d | N(d) | Result | Source |
|---|---|---|---|---|
| ℚ(√2) | 1+√2 (unit) | −1 | reflective ⇔ n ≤ 6 | Bugaenko 1990 |
| ℚ(√2) | 5+4√2 (prime above 7) | −7 | reflective for n ≤ 5; new polyhedra in dims 4–5; the n = 5 polytope has 20 facets, f-vector (96, 240, 228, 102, 20, 1), growth rate ≈ 14.137 | Guglielmetti thesis 2017* |
| ℚ(√5) | (1+√5)/2 (unit) | −1 | reflective ⇔ n ≤ 7 | Bugaenko 1984 |
| ℚ(√5) | (5+3√5)/2 = √5·ε², ε = (1+√5)/2, ≡ √5 mod unit squares | −5 | reflective for n ≤ 5; new in dim 5 | Guglielmetti thesis 2017* |
| ℚ(√5) | 3+2√5 (prime above 11) | −11 | reflective for n = 2 (quadrilateral); non-reflective for n = 3 (periodic diagram, loxodromic isometry), hence for all n ≥ 3 by §3 | Mcleod thesis §3.2.1 |
| ℚ(√5) | −3+2√5 (the other prime above 11) | −11 | reflective for n = 2, 3 (n = 3 polytope is a cube); n ≥ 4 open, and by §3 only n = 4 needs checking | Mcleod thesis §3.2.2 |
| ℚ(cos 2π/7) | 2cos(2π/7) | — | reflective for n = 2, 3, 4 | Bugaenko 1992 |

\* Read through an extraction tool, not directly. Check the notation (Θ₂ = √2,
Θ₅ = (1+√5)/2) and the norm calculations against the PDF before relying on them.

Bugaenko also found another reflective form in dimension 8 over ℚ(√5), with
discriminant −(1+√5). It is not in this family.

## 3. Monotonicity lemma (Bugaenko's theorem, with any totally positive c)

**Lemma.** Let K be totally real, L an admissible hyperbolic O_K-lattice, c ∈ O_K
totally positive, and L′ = L ⊥ O_K·u with (u,u) = c. If L′ is reflective, then L is
reflective. Moreover, a fundamental polytope for W(L) is the facet u^⊥ of a
fundamental polytope for W(L′).

Here W(·) is the group generated by reflections in *all* roots, and "reflective"
means [O′(L) : W(L)] < ∞.

**Corollary.** For each d, the set of n for which f_d^n is reflective is an
interval {2, …, N(d)}. If f_d^{n₀} is non-reflective, then f_d^n is non-reflective
for every n ≥ n₀. If f_d^n is reflective for some n ≥ 2, then f_d^2 is reflective.

### Proof

Write each x ∈ L′ as x = x_L + a(x)·u with x_L ∈ L and a(x) ∈ O_K. Then
(x,u) = a(x)·c, so

  (∗) (x,u)/c ∈ O_K for every x ∈ L′.

**Step 1: roots of L and roots of L′ orthogonal to u are the same.** If r is a
root of L with norm m, then (r,x) = (r,x_L) for every x ∈ L′, so
2(r,x)/m ∈ O_K, and r is still primitive in L′. So r is a root of L′. Conversely,
if r′ is a root of L′ with r′ ⊥ u, then a(r′) = 0 by (∗), so r′ ∈ L. It is
primitive in L, and the integrality condition restricted to L shows it is a root
of L. The vector u is itself a root of L′, because 2(u,x)/c = 2a(x) ∈ O_K.

**Step 2: choose a facet.** Assume L′ is reflective. Then W′ = W(L′) has finite
covolume, and its chambers are Coxeter polytopes with finitely many faces and
finite volume. Since r_u ∈ W′, the hyperplane H = u^⊥ ≅ ℍⁿ is a mirror. Choose a
chamber P′ with a facet F = P′ ∩ H. Then F has finite volume, and it is compact
if P′ is.

**Step 3: no odd angles at F.** Suppose a facet with outward root e meets F at
dihedral angle π/k with k odd. In the dihedral group ⟨r_e, r_u⟩ of order 2k, the
two reflections are conjugate: there is w with w r_u w⁻¹ = r_e. So w maps u^⊥ to
e^⊥, and wu ∈ ℝe. Since |wu| = |u|, at the identity embedding
(wu,u) = ±c·cos(π/k). But wu ∈ L′, so by (∗) the number ±cos(π/k) lies in O_K,
which makes it an algebraic integer.

This is impossible for odd k ≥ 3. With ζ = e^{iπ/k}, we have
2cos(π/k) = ζ⁻¹(1+ζ²) and 1 + ζ² = (1−ζ⁴)/(1−ζ²). Both ζ² and ζ⁴ are primitive
k-th roots of unity, so this quotient is a cyclotomic unit. So 2cos(π/k) is a unit
and cannot be divisible by 2.

**Step 4: every face of F lies in a mirror of W(L).** Every ridge R = F ∩ F_j has
angle π/k with k even. The dihedral group at R (order 2k) then contains the
reflection in the hyperplane through R perpendicular to H. That reflection lies in
W′, so its root r′ is a root of L′. Since r′ ⊥ u, Step 1 shows it is a root of L.
(When k = 2, take r′ to be the root of F_j.) So the hyperplane of H spanned by R
is a mirror of W(L).

**Step 5: F is a chamber of W(L).** Every mirror of W(L) in H has the form r^⊥ ∩ H
for a root r of L. By Step 1, r^⊥ is a mirror of W′ different from H. The relative
interior of a facet of a chamber meets no mirror except its own, so the interior
of F meets no mirror of W(L), and F lies inside a single chamber C of W(L). By
Step 4, each face hyperplane of F is a mirror of W(L). C is convex and meets none
of these mirrors in its interior, so C lies on F's side of each of them. Hence
C ⊆ F, and so C = F. So W(L) has a chamber of finite volume and finite covolume in
Isom(H). It sits inside the discrete group O′(L), so it has finite index. ∎

**Remarks**
- Over ℚ(√2), the only possible odd label is k = 3, but the proof does not use this.
- The orthogonal splitting L′ = L ⊥ O_K·u and the use of all roots (not just short
  roots) are essential: (∗) is exactly what fails without the splitting.
- **Built-in check for computations:** the Vinberg polytope in dimension n must
  be the facet −v_{n+1}^⊥ of the polytope in dimension n+1, with walls from the
  perpendicular roots at even-angle ridges. An odd angle at that facet means a bug.

## 4. Bounding d in the co-compact case

By §3, the problem reduces to the rank-3 forms ⟨−d, 1, 1⟩ over O_K, just as over ℚ.
What is needed is a rank-3 classification over O_K.

**Over ℤ[√2] it exists.** Mark, "The classification of rank 3 reflective
hyperbolic lattices over ℤ[√2]", *Math. Proc. Camb. Phil. Soc.* 164 (2018)
221–257, arXiv:1512.01133 (PhD thesis, UT Austin, 2015). There are 432 strongly
squarefree reflective lattices of signature (2,1) over ℤ[√2]. In rank 3, strongly
squarefree is equivalent to the determinant being squarefree. If (d) is a
squarefree ideal, then ⟨−d, 1, 1⟩ is strongly squarefree, so:

> f_d^n reflective for some n ≥ 2 ⟹ ⟨−d, 1, 1⟩ is isometric to one of Mark's 432 lattices.

- The appendix lists, for each lattice, the determinant, the shape of the polygon,
  the quadratic form and the simple roots, sorted by the norm of the determinant.
  The forms are not given in diagonal form, so an isometry test is needed.
- The method adapts Allcock's version of Nikulin's narrow-places argument to the
  real quadratic setting. To avoid slow Vinberg runs, Mark "walks around" the
  edges of the chamber instead.
- She also bounds the field: if D > 27935, or if D ≡ 2, 3 mod 4 and D > 6983,
  there are no reflective lattices over ℚ(√D). Here D is the squarefree integer
  defining the field, not the coefficient. Polygons with a short pair or close
  pair give sharper bounds: D > 1296, or D ≡ 2, 3 mod 4 and D > 324.

**Rank 4 over ℤ[√2]:** Bogachev classified the stably reflective rank-4 lattices
(*Doklady Math.* 99 (2019) 241–244). Stably reflective is a stronger condition,
using only short roots, so this does not bound d for n = 3.

**Other fields:** I found no rank-3 classification over ℤ[(1+√5)/2] or any other
ring. Elsewhere the known bounds are on the field (degree, discriminant), not on d.
The likely route is Mark's: adapt the Allcock–Nikulin method. Her short-pair and
close-pair bounds suggest it is feasible for ℚ(√5).

**Volume methods:** Belolipetsky, "Finiteness theorems for congruence reflection
groups" (arXiv:1008.0934), bounds field discriminants dimension by dimension using
Prasad's formula. The local factors at primes dividing d grow with N(p), so the
same inequalities would in principle bound N(d), but only for congruence groups and
with weak constants. I know of no explicit bound on d obtained this way.

**Other general results:** finitely many maximal arithmetic reflection groups
(Nikulin; Agol–Belolipetsky–Storm–Whyte); no reflective arithmetic forms in
dimension n ≥ 30 (Vinberg); no co-compact examples known for n ≥ 9.

## 5. What has been done with Mark's list

I could not search citation databases, so this may not be exhaustive.

- **Belolipetsky's survey** (Bull. AMS 53 (2016)) reports the 432 lattices as the
  n = 2 step of the classification programme.
- **Bogachev** cites it in his rank-4 ℤ[√2] work and in "From Geometry to
  Arithmetic of Compact Hyperbolic Coxeter Polytopes" (*Transformation Groups* 28
  (2023) 77–105), where its exact role could not be checked behind the paywall.
- **No one appears to have** extracted the diagonal ⟨−d, 1, 1⟩ entries, combined
  them with the face theorem to classify all squarefree d over ℤ[√2] in all
  dimensions, or done the rank-3 classification needed for ℚ(√5). So this project
  looks new.

**Immediate consequences of §3 for existing results:**
- d = 3+2√5 is non-reflective for all n ≥ 3.
- For d = −3+2√5, only n = 4 is open: if it fails, every higher n fails.
- ⟨−(5+4√2), 1, 1⟩ must be one of Mark's 432 lattices, which gives a free check of
  the extraction step.

## 7. Claude Code brief (consolidated)

````markdown
# Project ReflectZ2: −d·x₀² + x₁² + … + xₙ² over ℤ[√2]

## Background
K = ℚ(√2), O_K = ℤ[√2], embeddings id: √2 ↦ +√2 and σ: √2 ↦ −√2. For d ∈ O_K with
d > 0 and σ(d) < 0, f_d = −d·x₀² + x₁² + … + xₙ² is admissible, so
Γ_d = O'(f_d, O_K) is a cocompact arithmetic lattice in Isom(ℍⁿ). L_d is
reflective if the reflection subgroup has finite index in Γ_d.

References to read first (fetch from arXiv; if that fails, stop and ask me):
- A. Mark, Publ. Mat. 59 (2015), arXiv:1207.4822 (the ℚ case, p prime)
- J. Mcleod, arXiv:1007.2299, and his Durham PhD thesis (2013), including the
  appendices on infinite-order isometries
- A. Mark, rank 3 reflective lattices over ℤ[√2], arXiv:1512.01133
- R. Guglielmetti, PhD thesis, Fribourg 2017 (AlVin; the case d = 5+4√2)

**Goal:** a complete classification of the squarefree admissible d (where (d) is
a squarefree ideal) for which f_d is reflective, with the exact range of n for
each. Give Coxeter diagrams for the reflective cases and checkable certificates for
the non-reflective ones.

## Proven lemma (use it; write it up in docs/monotonicity.md from my notes)
If L ⊥ ⟨c⟩ is reflective, with c totally positive, then L is reflective, and a
fundamental polytope of W(L) is the facet u^⊥ of the one for L ⊥ ⟨c⟩.
Consequences:
- the reflective n for each d form an interval {2, …, N(d)};
- reflective for some n ⟹ reflective for n = 2;
- non-reflective at n₀ ⟹ non-reflective for all n ≥ n₀.
The key step of the proof: dihedral angles at the facet u^⊥ are never π/odd,
because cos(π/k) is not an algebraic integer for odd k ≥ 3.

## Ground rules
- Every decision uses EXACT arithmetic in ℤ[√2] and ℚ(√2). Represent elements as
  a + b√2 with Python ints or Fractions. Decide the sign of a + b√2 exactly by
  comparing a² with 2b² and checking the signs of a and b. Floats are allowed only
  for ordering heuristics and display, never for accepting or rejecting anything.
- Start in plan mode and write methods.md before writing code.
- Every mathematical claim must be backed by a stored artefact and a test that
  re-checks it.
- Write any doubts in OPEN_QUESTIONS.md; do not assume them away.
- Commit after each phase.

## Phase 0: Tooling
1. Exact-arithmetic module for ℤ[√2] and ℚ(√2): ring operations, conjugation,
   norm, sign at each embedding, divisibility, gcd, factorisation of small
   elements. Unit tests.
2. Try to build AlVin and CoxIter (github.com/rgugliel/AlVin,
   github.com/rgugliel/CoxIter). If they build, use them as INDEPENDENT
   cross-checks only.

## Phase 1: Candidate list from Mark's classification
1. Parse Mark's appendix into data/mark432.json: Gram matrix, determinant, simple
   roots. Check every entry: the determinant agrees with the Gram matrix, and the
   listed roots are roots of that lattice. If any entry fails, STOP and report.
2. For entries with determinant ≡ −d modulo unit squares, where d > 0, σ(d) < 0
   and (d) is squarefree, decide exactly whether the lattice is isometric to
   ⟨−d, 1, 1⟩. Store an explicit basis change over ℤ[√2] as a certificate, or
   record the invariant that proves non-isometry.
3. The output is the COMPLETE list of squarefree admissible d with ⟨−d,1,1⟩
   reflective. Every other squarefree admissible d is non-reflective in all
   dimensions (cite Mark plus the lemma). Record those without computation.
4. Checks:
   - d = 1+√2 and d = 5+4√2 must both be on the list.
   - Do not identify the two primes above a split p.
   - Note that the totally positive units of ℤ[√2] are exactly the squares of
     units, so each principal ideal gives exactly one admissible d up to unit
     squares. Verify this.
   - Report how many entries turn out to be diagonal.
5. STOP and report the list to me.

## Phase 2: Vinberg's algorithm over ℤ[√2] (Bugaenko's version)
Basis v₀, …, vₙ with Gram matrix diag(−d, 1, …, 1), control vector v₀.

1. **Stabiliser roots.** Compute the root system orthogonal to v₀ (roots of I_n
   over ℤ[√2]). Do not assume it is B_n; confirm or correct the simple roots
   eᵢ = vᵢ₊₁ − vᵢ and eₙ = −vₙ.
2. **Roots.** A root is a primitive vector e with totally positive norm m such
   that m | 2kᵢ for i ≥ 1 and m | 2d·k₀. The possible m are the totally positive
   divisors of 2d modulo unit squares.
3. **Enumeration.** Generate candidates with k₀ > 0 at id, in increasing order of
   d·k₀²/m at id. Bound every coordinate using both the id condition and the
   conjugate condition −σ(d)σ(k₀)² + Σσ(kᵢ)² = σ(m). Impose the chamber
   inequalities of the stabiliser roots. Cache the solutions of
   Σkᵢ² = m + d·k₀².
4. **Acceptance.** Accept a candidate if (e, eⱼ) ≤ 0 at id for every root
   accepted so far, including others in the same batch.
5. **Termination.** P is compact if and only if it has a vertex and every elliptic
   subdiagram of rank n−1 lies in exactly two elliptic subdiagrams of rank n.
   - Decide "elliptic" by exact positive-definiteness of Gram submatrices.
   - Edge types: cos² ∈ {cos²(π/k) : k = 2, 3, 4, 6, 8}; note that
     cos²(π/8) = (2+√2)/4 lies in K. A value > 1 means a dotted edge. A value of
     exactly 1 raises an error, since parallel mirrors are impossible here.
   - Cross-check every compact polytope with CoxIter if it is available.
6. **Scope.** For each d on the Phase 1 list, increase n from 3 up to the first
   n₀ that does not terminate within the caps. Record n₀ and do not go above it.

**Calibration (must pass before Phase 3):**
- (a) Same code with K = ℚ: reproduce Mark's p = 5 (2 ≤ n ≤ 8) and Mcleod's
  p = 3 (2 ≤ n ≤ 13), including the number of faces.
- (b) d = 1+√2: reflective for n ≤ 6, does not terminate at n = 7 (Bugaenko).
- (c) d = 5+4√2: reflective for n ≤ 5 (Guglielmetti). The n = 5 polytope has 20
  facets and f-vector (96, 240, 228, 102, 20, 1). Check the form against
  Guglielmetti's thesis first.
- (d) For each d on the list, the n = 2 polygon must match Mark's entry (same
  sides and angles, roots equal up to the Phase 1 isometry).
- (e) Facet test: whenever (d, n+1) terminates, the facet −v_{n+1}^⊥ with walls
  from the perpendicular roots at even-angle ridges must reproduce the polytope
  for (d, n). An odd angle there raises an error.
- (f) Where AlVin builds, compare root lists against it on a few cases.

## Phase 3: Non-reflectivity certificates
For each d, give ONE certificate, at n₀: an infinite-order element of O'(L_d)
that preserves the fundamental polytope of the reflection subgroup. Follow the
method in Mcleod's thesis and Mark's paper (a symmetry of a subdiagram of the
found roots, extended to an integral isometry).

Each certificate must contain:
- a matrix g with entries in ℤ[√2] in the basis v₀, …, vₙ (and integral inverse);
- an exact check that gᵀ·F·g = F;
- an exact proof that g has infinite order;
- the precise argument that g preserves the polytope.

Write a standalone verify_certificate.py that re-checks every certificate from
JSON alone. The lemma covers every n > n₀; mark those as "non-reflective (by
monotonicity from n₀)".

## Phase 4: Outputs
- results.csv: ideal, d, N(d), the range of reflective n, n₀, the certificate id,
  and the number of faces in each dimension.
- diagrams/ (TikZ and PNG, plus JSON root lists and Gram matrices).
- report.md: the classification table; the relation between |N(d)| and N(d),
  compared with ℚ (d = 1, 2, 3, 5, 7, 11, 17 give maximal n = 19, 14, 13, 8, 3, 4,
  3); and whether split, inert and ramified primes behave differently.
- tests/ covering the arithmetic, the calibration cases and the certificate
  verifier. All tests must pass.

## Stopping points
- after Phase 1 (the complete candidate list);
- if any entry of Mark's list fails the consistency checks;
- if any calibration case fails.
````

### Possible extension to ℚ(√5)
- The edge types change: cos²(π/5) lies in ℚ(√5), and cos²(π/8) does not.
- Calibration cases: (1+√5)/2 (n ≤ 7), √5 ≡ (5+3√5)/2 (n ≤ 5), 3+2√5 (n = 2
  only), −3+2√5 (n = 2, 3; n = 4 open).
- There is no rank-3 classification, so the candidate list needs either an
  arbitrary norm cut-off or a new Allcock–Mark style rank-3 analysis.
