# Project: Reflectivity of −d·x₀² + x₁² + … + xₙ² over ℤ[√2], d prime

## Background
Let K = ℚ(√2), O_K = ℤ[√2], with embeddings id: √2 ↦ +√2 and σ: √2 ↦ −√2.
For d ∈ O_K with d > 0 and σ(d) < 0, the form
    f_d = −d·x₀² + x₁² + … + xₙ²
is admissible: it is hyperbolic at id and positive definite at σ. So
Γ_d = O'(f_d, O_K) is a co-compact arithmetic lattice in Isom(ℍⁿ).
L_d is said to be reflective if the subgroup generated by reflections has
finite index in Γ_d.

This is the co-compact analogue of:
- A. Mark, "Reflection groups of the quadratic form −px₀²+x₁²+…+xₙ² with p prime",
  Publ. Mat. 59 (2015), arXiv:1207.4822
- J. Mcleod, "Hyperbolic reflection groups associated to the quadratic forms
  −3x₀²+x₁²+…+xₙ²", arXiv:1007.2299, and his Durham PhD thesis (2013),
  especially the appendices on infinite-order isometries
- Bugaenko (1990): d = 1+√2 is reflective if and only if n ≤ 6

**Goal:** for each admissible prime parameter d (definition below) with
|N(d)| ≤ 50, and each 2 ≤ n ≤ 10, decide whether L_d is reflective. For the
reflective cases, give the Coxeter diagram. For the non-reflective cases, give
a checkable certificate. Then extend to every n beyond the range computed.

Points to check and document:
- The totally positive units of ℤ[√2] are exactly the squares of units. So
  each principal prime ideal gives exactly one admissible d up to unit squares.
  Verify this.
- Do NOT identify the two primes above a split p. Galois conjugation does not

## Phase 2: Vinberg's algorithm over ℤ[√2] (Bugaenko's version)
Basis v₀, …, vₙ with Gram matrix diag(−d, 1, …, 1), control vector v₀.

1. **Stabiliser roots.** Do not assume the stabiliser of v₀ is the B_n system.
   Enumerate all roots with k₀ = 0, i.e. all roots of I_n over ℤ[√2], and
   compute its root system. Confirm (or correct) the simple roots
   eᵢ = vᵢ₊₁ − vᵢ for 1 ≤ i < n and eₙ = −vₙ.
2. **Root definition.** A root is a primitive vector e = Σ kᵢvᵢ whose norm
   m = (e,e) is totally positive, with 2(e, x)/m ∈ O_K for all x ∈ L.
   Concretely: m | 2kᵢ for i ≥ 1, and m | 2d·k₀. The possible m are the
   totally positive divisors of 2d, taken modulo squares of units. Compute this
   finite list for each d.
3. **Enumeration.** Generate candidates with k₀ > 0 at id, in increasing order
   of the distance d·k₀²/m (evaluated at id). The conjugate condition
   −σ(d)σ(k₀)² + Σσ(kᵢ)² = σ(m) bounds |σ(k₀)| and every |σ(kᵢ)|, and the id
   condition bounds |kᵢ|. Together they make each batch finite. Impose
   k₁ ≥ k₂ ≥ … ≥ kₙ ≥ 0 at id, or whatever the chamber of the stabiliser roots
   from step 1 requires. Solve Σ kᵢ² = m + d·k₀² by bounded search over ℤ[√2]
   in both embeddings. Cache the solutions.
4. **Acceptance.** Accept a candidate if (e, eⱼ) ≤ 0 at id for every root
   accepted so far. Within a batch, check candidates against each other as well.
5. **Termination test** after each batch: the polytope P cut out by the
   accepted roots is compact if and only if it has at least one vertex AND every
   elliptic subdiagram of rank n−1 lies in exactly two elliptic subdiagrams of
   rank n (Vinberg's criterion).
   - Decide "elliptic" by exact positive-definiteness of the Gram submatrix,
     i.e. leading principal minors positive at id. Use normalised entries
     gᵢⱼ = (eᵢ,eⱼ)/√(mᵢmⱼ) and work with squared values in ℚ(√2).
   - Edge types: cos²(π/k) for k = 2, 3, 4, 6, 8. Note that
     cos²(π/8) = (2+√2)/4 lies in K. A value > 1 means the mirrors are
     ultraparallel (dotted edge). A value exactly 1 (parallel mirrors) is
     IMPOSSIBLE for a co-compact group, so raise an error if it appears.
   - Cross-check every compact polytope with CoxIter if it is available.
6. Cap the number of batches and the distance. Record "not terminated" as
   "undetermined" so it can go to Phase 3.

## Phase 3: Non-reflectivity certificates
For each (d, n) that does not terminate, prove non-reflectivity by finding an
infinite-order element of O'(L_d) that preserves the fundamental polytope of
the reflection subgroup. Follow the method of Mcleod's thesis and Mark's paper:
a symmetry of a subdiagram of the found roots, extended to an integral isometry.

Each certificate must contain:
- a matrix g with entries in ℤ[√2] in the basis v₀, …, vₙ (and integral
  inverse);
- an exact check that gᵀ·F·g = F for the Gram matrix F;
- an exact proof that g has infinite order: for example, an eigenvalue at id of
  absolute value > 1, or gᵏ ≠ I for k up to the bound allowed by the possible
  orders of finite-order elements;
- the precise argument that g preserves the polytope, with the roots it
  permutes listed.
Write a standalone verify_certificate.py that re-checks every certificate from
JSON alone.

**Extending to all n:** either give a construction of g that works uniformly in
n (as Mcleod and Mark do), or cite a precise lemma that passes non-reflectivity
from n to n+1 and state its hypotheses. If neither is available, report the
result only for the dimensions actually checked, and add the gap to
OPEN_QUESTIONS.md.
