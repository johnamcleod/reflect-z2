# Methods

Reflectivity of f_d = −d·x₀² + x₁² + … + xₙ² over O_K = ℤ[√2], K = ℚ(√2).

## Notation

- **Embeddings.** id: √2 ↦ +√2 and σ: √2 ↦ −√2.
- **Lattice.** L = O_K^{n+1} with basis v₀, …, vₙ and Gram matrix F = diag(−d, 1, …, 1).
- **Admissible d.** d > 0 and σ(d) < 0. Then f_d has signature (n,1) at id and is positive definite at σ. So Γ_d = O'(f_d, O_K) is a co-compact arithmetic lattice in Isom(ℍⁿ).
- **Reflective.** L is reflective if [Γ_d : W_d] < ∞, where W_d is the subgroup generated by reflections.
- **Decomposition.** Γ_d = W_d ⋊ H, where H = Sym(P) and P is the fundamental chamber of W_d. Hence L is reflective iff H is finite (thesis Def. 1.1.1; Vinberg).

## Exact arithmetic

- **Representation.** Elements of K are a + b√2 with a, b ∈ ℚ (`fractions.Fraction`). Elements of O_K have a, b ∈ ℤ.
- **Sign.** sign(a + b√2) is decided exactly: if a and b have the same sign, that is the answer. Otherwise compare a² with 2b².
- **Positivity.** Every "≥ 0", "> 1" and "= 0" in the algorithm goes through this sign function, applied at id, at σ, or at both. Floats appear only as sort keys and in display output.
- **Ring tooling.** Norm N(x) = x·σ(x). Units are ±ε^k with ε = 1+√2 and N(ε) = −1. O_K is a Euclidean domain for |N|, which gives gcd. The prime factorisation of small elements is done through ideal norms.
- **Generic interface.** The Vinberg code calls only an abstract `Ring` interface. `IntegerRing` (ℤ, with one embedding) runs the ℚ calibrations through exactly the same code path.

## Phase 1: parameters

- **Prime ideals with N(𝔭) ≤ 50:**
  - the ramified prime (√2);
  - the two primes above each split p ≡ ±1 (mod 8): p = 7, 17, 23, 31, 41, 47;
  - the inert (p) with p ≡ ±3 (mod 8): p = 3 and 5, of norm 9 and 25.

  That gives 15 ideals. The calibration unit d = 1+√2 makes 16 parameters.
- **Admissible generators.** O_K has class number 1, so each 𝔭 = (π). Multiplying by ±ε^k gives a generator with sign pattern (+, −). The unit ε has signs (+, −), so it toggles the σ-sign, and −1 flips both signs.
- **Uniqueness.** The totally positive units are exactly ε^{2ℤ}, the unit squares. Proof: a unit u = ±ε^k is totally positive iff N(u) = +1 and u > 0, i.e. iff k is even and the sign is +. A test checks this exactly. So the admissible generators of 𝔭 form one ε^{2ℤ}-orbit.
  - Scaling x₀ by ε^k shows that d and d·ε^{2k} give isometric forms.
  - So each ideal yields one parameter.
- **Canonical representative.** Take the orbit element minimising max(|d|, |σd|). Ties occur when |d·σ(d)| = |N(d)| and the two values swap, e.g. 1+√2 against √2−1. Ties are broken by the larger value at id, which keeps Bugaenko's d = 1+√2.
- **The two primes above a split p are kept separate.** If π has signs (+, −), then −σ(π) also has signs (+, −) and generates σ(𝔭). But f_π and f_{−σπ} are not Galois conjugate as forms with respect to the fixed embedding id. Applying σ to f_π gives a form that is positive definite at id.

## Phase 2: Vinberg's algorithm (Bugaenko's version)

1. **Stabiliser.** Enumerate every root e with k₀ = 0, i.e. every root of the positive-definite lattice I_n over O_K, of every admissible norm m. Compute the root system and check that the simple system is e_i = v_{i+1} − v_i (1 ≤ i < n), e_n = −v_n, which is type B_n.
   - Over O_K this is not automatic. A norm-2 vector such as v₁ + √2·v₂ is excluded only because its norm 1 + 2 = 3 is not a permitted root norm, so this has to be checked.
   - If extra roots exist, we use the chamber they actually define.
2. **Roots.** A root is a primitive e = Σkᵢvᵢ with totally positive norm m = (e,e) such that 2(e,x)/m ∈ O_K for all x ∈ L. Equivalently m | 2kᵢ for i ≥ 1 and m | 2d·k₀.
   - Primitivity together with these conditions gives m | 2d.
   - Every divisor of 2d has a totally positive associate, because N(ε) = −1. So the possible m are the totally positive divisors of 2d modulo ε^{2ℤ}. In the generic case that is 6 classes: 1, 2 + √2 (= √2·ε), 2, and associates of d, √2·d and 2d.
   - Scaling e by a unit u changes m to u²m and gives the same reflection, so it is enough to work modulo unit squares.
   - For a unit u, u·e is again a root. The orientation condition "k₀ > 0 at id" fixes the sign, but scaling by ε^{2k} produces many representatives. We normalise each candidate to the representative of m in the fixed list; the divisor classes are distinct modulo squares, so this representative is unique.
3. **Enumeration.**
   - **Distance.** The batch key is δ = d·k₀²/m, evaluated at id; it is sinh² of the distance to v₀. Batches are processed in increasing order of δ. Floats only sort the batches; ties are merged by exact comparison in K.
   - **Choice of k₀.** For each (m, k₀), the conjugate equation Σσ(kᵢ)² = σ(m) − σ(d)σ(k₀)² must be ≥ 0. Since −σ(d) > 0, it bounds |σ(k₀)|. The id-side bound δ ≤ δ_max bounds k₀. So each batch has finitely many k₀.
   - **Solving Σkᵢ² = m + d·k₀².** A DFS over k₁ ≥ k₂ ≥ … ≥ kₙ ≥ 0 at id, carrying the residuals at both id and σ. Each kᵢ satisfies kᵢ² ≤ R_id and σ(kᵢ)² ≤ R_σ. The ordering bounds kᵢ by k_{i−1} at id, and the elements of O_K in a box are finite. Partial assignments that fail m | 2kᵢ are pruned. Results are cached.
   - **Primitivity and orientation.** The gcd of (k₀, …, kₙ) must be a unit. Since k₀ > 0 at id, the root points away from v₀'s side.
4. **Acceptance.** A candidate is accepted if (e, e_j) ≤ 0 at id for every root accepted so far, including roots accepted earlier in the same batch. Within a batch, any surviving candidate that pairs positively with another candidate in the same batch has its order decided by the stated rule. Vinberg's algorithm guarantees that candidates at equal distance that survive are mutually non-obtuse; we assert this rather than assume it.
5. **Termination (co-compact).** Let P_k be the polytope cut out by the accepted roots. It is compact iff
   - it has at least one vertex (an elliptic subdiagram of rank n), and
   - every elliptic subdiagram of rank n−1 lies in exactly two elliptic subdiagrams of rank n (Vinberg; thesis Prop. 2.2.7).
   - **Ellipticity.** A subdiagram is elliptic iff its normalised Gram matrix is positive definite. That matrix is congruent to the raw Gram matrix G_S = ((eᵢ, eⱼ)) via diag(m^{-1/2}), so we test G_S directly using exact leading principal minors, at id, with entries in O_K. No square roots are needed.
   - **Edge labels.** c = (eᵢ, eⱼ)²/(mᵢmⱼ) ∈ K, compared exactly with cos²(π/k) = 0, 1/4, 1/2, 3/4, (2+√2)/4 for k = 2, 3, 4, 6, 8.
     - c > 1 means ultraparallel (dotted).
     - c = 1 (parallel) is impossible in the co-compact case and raises an error.
     - Any other value also raises an error, because a non-Coxeter angle means a bug.
   - **ℚ calibration** (non-compact) uses Vinberg's finite-volume criterion instead. Every elliptic subdiagram of rank n−1 must lie in exactly two subdiagrams, each either elliptic of rank n or parabolic of rank n−1. A parabolic subdiagram is one where every connected component is positive semidefinite of corank 1.
   - Every terminated polytope is cross-checked with CoxIter (compactness or finite volume, f-vector, Euler characteristic).
6. **Caps.** Each (d, n) run has a maximum number of batches, a maximum δ and a wall-clock limit. Hitting a cap records the case as `undetermined`, to be handled in Phase 3.

### Calibration (must pass before the full grid)

- **(a)** K = ℚ: p = 5 terminates for 2 ≤ n ≤ 8 and not at n = 9; p = 3 terminates for 2 ≤ n ≤ 13 and not at n = 14 (within the caps). Face counts are compared with the papers' root tables and with AlVin.
- **(b)** d = 1+√2: terminates for n ≤ 6 and does not terminate at n = 7.
- **(c)** Root lists are compared with AlVin (`-k="Q[sqrt 2]" -qf <-d>,1,…,1`) for several (d, n), matching up to unit scaling and ordering.

## Phase 3: non-reflectivity certificates

For a case that does not terminate we look for g ∈ O'(L) of infinite order with g(P) = P. Then H is infinite, so L is not reflective.

1. **Search.** Run Vinberg further, which yields a finite set R of facet roots of P. Look for pairs of root configurations (S ∪ {r}, S′ ∪ {r′}) in R where:
   - S and S′ are elliptic of rank n;
   - r ∉ span(S) and r′ ∉ span(S′);
   - the Gram matrices agree entrywise, in the order of a bijection.

   Then set g = R′·R⁻¹, where the columns of R are the n+1 vectors in the basis v.
2. **Checks (exact)**, for each candidate g:
   - every entry of g lies in O_K;
   - gᵀFg = F;
   - (g v₀, v₀) < 0 at id, so g preserves the future cone and lies in O';
   - g ≠ 1.

   Integral inverse: from gᵀFg = F we get det(g)² = 1, so g⁻¹ = adj(g)·det(g) is integral. The verifier also computes g⁻¹ and checks g·g⁻¹ = 1 explicitly.
3. **Infinite order.** Compute χ_g(x) ∈ O_K[x] and its norm N(χ_g) = χ_g·σ(χ_g) ∈ ℤ[x].
   - If g had finite order, N(χ_g) would be a product of cyclotomic polynomials. We factor exactly (sympy over ℚ) and exhibit a non-cyclotomic factor.
   - We also isolate a real root > 1 of χ_g at id exactly (rational interval with a sign change, then bisection), so g is loxodromic.
4. **g(P) = P.**
   - Let v be the point where the mirrors of S meet; it is a vertex of P.
     - For an acute-angled polyhedron, an elliptic subdiagram of facets corresponds to a face (Vinberg; thesis Prop. 2.2.9). The facets of S really are facets of P, because Vinberg's algorithm outputs facets of P.
   - g maps the halfspaces {(x, s) ≤ 0 : s ∈ S} onto {(x, s′) ≤ 0 : s′ ∈ S′}, since g(s) = s′ exactly. The cone of P at v is cut out by exactly these n halfspaces, because S has rank n and v is a simple vertex. Likewise the cone of P at v′ = g·v is cut out by S′.
   - So g(P) and P have the same local cone at v′, and therefore share interior points. g normalises W, so g(P) is a W-chamber, and two chambers with a common interior point are equal. Hence g(P) = P.
   - The certificate lists S, S′, r, r′ and the bijection. The verifier re-checks that S and S′ are elliptic, that their Gram matrices match, that every listed vector is a root of L, and that each root is a facet. The facet check is not certifiable from JSON alone, since it relies on the run that produced the roots. The verifier re-runs the deterministic Vinberg prefix up to the largest δ involved and confirms that the roots appear in it.
   - Doubts about this step are recorded in OPEN_QUESTIONS.md.
5. **Base vertex.** Normally S is the stabiliser simple system at v₀ (its roots are facets by step 1 of Vinberg's algorithm), and r = v₀. If no certificate is found that way, `search(..., any_base=True)` also tries every other found elliptic rank-n set S as the base, with v = its vertex vector. A product of two finite-order symmetries with different bases is still a symmetry of P, since each factor is. For such certificates the verifier always runs the facets check, on S_from as well as S_to, even without `--facets`. This was needed only for p47b at n = 2.
6. **AlVin cross-check.** We compare with the output of AlVin's infinite-symmetry module where it reports one.

### Reflective super-lattice check (for each certificate)

Following thesis Fig. 3.2, where an infinite-order isometry is a product of two reflections in a larger reflection group:

1. **Decompose g.** Find vectors a, b ∈ K^{n+1} of positive norm with g = R_a R_b (or g² = R_a R_b). Candidates come from:
   - the 2-plane spanned by the real eigenvectors of g, using exact eigenvectors over K when χ_g has a quadratic factor over K, or over K(√Δ) when needed;
   - pairs of Vinberg roots r, r′ with g(r) = r′.
2. **Build L′.** L′ is the smallest O_K-lattice containing L that is stable under R_a and R_b. Iterate L ↦ L + R_a L + R_b L using Hermite normal form over O_K, which is a PID. Abort if the result leaves L^# = F⁻¹L, the dual lattice. Any overlattice on which F is O_K-integral lies inside L^#.
3. **Vinberg on L′.** If L′ exists, then g ∈ W(L′). Run Vinberg on L′ with the same control vector v₀. The roots of L′ are vectors x with N·x ∈ L, where N is the exponent of L′/L. So we reuse the same DFS on y = N·x with norm N²m, filtered by y ∈ N·L′, where m runs over the norms permitted by the crystallographic condition for L′.
4. **Outcome.** Record one of:
   - L′ reflective (with its diagram and face count);
   - L′ non-reflective or undetermined;
   - no decomposition found.

   L itself remains non-reflective in every case. A reflective L′ explains the infinite symmetry, but [Γ(L) : W(L)] is still infinite.

## Extension to all n

- **Theorem (Bugaenko 1990, Thm 2; thesis Thm 3.0.8).** If f = f′ ⊕ u, where u is a unimodular rank-1 form, then the fundamental polytope of the maximal reflection subgroup for f′ is a face of the one for f.
  - We have f_d^{(n+1)} = f_d^{(n)} ⊕ ⟨1⟩, and ⟨1⟩ is unimodular over O_K.
  - So non-reflective at n₀ implies non-reflective for every n ≥ n₀. A face of a finite-volume polytope with finitely many facets has finitely many facets.
  - Mark's Prop. 3.1 gives a self-contained proof over ℤ. We re-derive it over O_K in OPEN_QUESTIONS.md, with the angles π/4 and π/8 adjacent to the norm-1 root e_{n+1} = −v_{n+1}, before relying on it.
- **Cases still reflective at n = 10.** These would be reported only for the dimensions checked. Vinberg's theorem rules out compact arithmetic reflection groups for n ≥ 30, which still leaves the gap 11 ≤ n ≤ 29.

## Brief 2: complete classification over ℤ[√2] (additional_notes.md §7)

- **Inputs.**
  - The monotonicity lemma (docs/monotonicity.md): the reflective n for each d form an interval {2, …, N(d)}.
  - Mark's theorem: every strongly squarefree reflective rank-3 lattice over ℤ[√2] appears in her table. If (d) is squarefree, ⟨−d,1,1⟩ is strongly squarefree (for rank 3 this means det squarefree).
- **Table.**
  - `tools/parse_mark.py` reads the TeX source of arXiv:1512.01133 (Appendix B) into `data/mark_table.json`. The source itself is not committed.
  - `reflect/mark.py` checks every entry exactly:
    - symmetric Gram matrix, signature (2,1) at id, positive definite at σ;
    - det = δ, with N(δ) as printed;
    - (δ) squarefree, form unscaled;
    - the listed vectors are roots of the stated norms;
    - pairwise non-obtuse, with the printed angle string.
- **Candidates.** C = {canonical(−δ)} over all entries (`reflect/candidates.py`), 70 values.
  - −δ is admissible for every entry: δ < 0 at id and σ(δ) > 0.
  - Totally positive units are squares, so each entry gives exactly one d.
- **Decision.** Every d ∈ C is decided directly at n = 2 (`reflect/decide2.py`): our Vinberg run either terminates, or a certificate is found. D ⊆ C is the reflective set. Every squarefree admissible d ∉ C is non-reflective for all n ≥ 2, by Mark plus the lemma.
- **Calibration (d)** (`reflect/isometry.py`).
  - For d ∈ D, an isometry ⟨−d,1,1⟩ → L carries chambers to chambers after composing with W. So it maps Mark's listed simple roots r_i to u_i·s_j, where s_j are our simple roots and u_i are units positive at id: a simple root is fixed by its mirror only up to such a unit.
  - We enumerate these injections, solve for φ on three independent roots, and keep φ iff φ and φ⁻¹ are integral and φᵀFφ = G.
  - Each d ∈ D must match at least one entry.
- **Calibration (e)** (`reflect/facet.py`): for each terminated pair (d, n), (d, n+1), the facet −v_{n+1}^⊥ reproduces the (d, n) polytope.
