# arXiv submission metadata (draft — review before submitting)

**Title:** Reflectivity of the quadratic forms -d x_0^2 + x_1^2 + ... + x_n^2 over Z[sqrt 2]: a computer-assisted classification

**Authors:** John Mcleod

**Primary category:** math.GT (Geometric Topology)
**Cross-lists:** math.NT (Number Theory), math.GR (Group Theory)

**MSC 2020:** 20F55 (reflection and Coxeter groups), 11E12 (quadratic forms over global rings), 22E40 (discrete subgroups of Lie groups), 51F15

**Comments:** 16 pages, 4 tables, 1 figure. Ancillary files contain the verifier, code, all certificates and chamber data.

**Abstract** (plain text for the submission form):

Let d be a squarefree element of Z[sqrt2] with d > 0 > sigma(d). The form f_d^n = -d x_0^2 + x_1^2 + ... + x_n^2 then defines a cocompact arithmetic group acting on hyperbolic n-space. We study for which (d,n) this group is generated by reflections up to finite index. A monotonicity lemma shows that the reflective n form an interval {2,...,N(d)}. Reflectivity of f_d^n for some n therefore forces <-d,1,1> to be reflective, so it should appear in A. Mark's classification of strongly squarefree reflective rank-3 lattices over Z[sqrt2]. Mark's table yields 70 candidate values of d. For each of them, and one further value, we determine N(d) by Vinberg's algorithm together with exactly checkable certificates of non-reflectivity at N(d)+1. There are 27 reflective d, with N(d) between 2 and 6, and 44 values that are non-reflective in every dimension. Six reflective pairs (d,n) appear to be new, including new compact Coxeter polytopes in dimensions 3, 4 and 5. One of them is d = -1+3sqrt2, n = 2: the lattice <1-3sqrt2,1,1> is reflective with a compact hexagonal chamber, yet it is isometric to no entry of Mark's table, so that table is incomplete. Completeness of our list therefore rests on an explicit, weaker hypothesis about the determinants occurring in Mark's table, which we state and discuss. All decisions use exact arithmetic in Q(sqrt2), and all certificates are re-checkable by an independent verifier.
